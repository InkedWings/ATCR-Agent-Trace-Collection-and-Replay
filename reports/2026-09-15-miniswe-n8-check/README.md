全程新增错误中 473/686 集中在 `django__django-11910`。抽查发现其 `tool-020`、`tool-046` 使用录制日期写死的 migration 文件名（`0002_auto_20260907_1813.py`、`0002_auto_20260907_1821.py`），本轮均标记 native error；这提示动态文件名是可能原因，尚未凭工具 stderr 逐项确认。本次只核对结果，没有修改 trace 或运行中的实验。
